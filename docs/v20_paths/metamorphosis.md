# Путь Преображения (Path of Metamorphosis)


| | |
|---|---|
| Прозвище | Метаморфисты (Metamorphosists) |
| Добродетели | Убеждённость (Conviction) + Инстинкт (Instinct) |
| Облик (Bearing) | Бесчеловечность (Inhumanity): броски с Запугиванием (Intimidation), а также с Манипуляцией (Manipulation), если цель запугивают |
| Кто следует | Почти исключительно Цимисхи (Tzimisce) |

Вампир — ступень эволюции, но не последняя. Метаморфисты стремятся превзойти вампиризм, изменяя плоть Изменчивостью (Vicissitude) и добывая знание экспериментами, в том числе над собой.

## Иерархия грехов (Hierarchy of Sins)

| Рейтинг | Грех | Реализация |
|---|---|---|
| 10 | Откладывать кормёжку, когда голоден | 🔧 таймер голода |
| 9 | Предаваться удовольствиям | ❓ |
| 8 | Спросить у другого знание | ❓ |
| 7 | Поделиться знанием | ❓ |
| 6 | Отказаться убить, если это даст знание | ❓ |
| 5 | Не «оседлать» безумие (ride the wave) | 🔧 безумие без контроля |
| 4 | Считаться с нуждами других | ❓ |
| 3 | Не экспериментировать, даже с риском для себя | ❓ |
| 2 | Не изменять собственное тело | 🔧 давно не применял Изменчивость (Vicissitude) на себя |
| 1 | Сострадание к другим | ❓ |

## Искупление (Atonement)

| Поступок | Почему это угодно Пути | Реализация |
|---|---|---|
| Изменить собственное тело Изменчивостью (Vicissitude) | Шаг к преображению | 🔧 `COMSIG_POWER_ACTIVATE` для Изменчивости с целью на себя |
| Изменить чужое тело Изменчивостью | Эксперимент ради знания | 🔧 `COMSIG_POWER_ACTIVATE` для Изменчивости на другую цель |
| Покормиться сразу, как пришёл голод | Голод отвлекает от цели | 🔧 кормёжка вскоре после начала голода |
| «Оседлать волну» (ride the wave): успешный бросок Инстинкта в безумии | Познать Зверя, чтобы превзойти его | 🔧 механика «оседлать волну» |
| Вскрыть труп сверхъестественного существа | Изучить иные формы бытия | 🔧 вскрытие трупа вампира, оборотня и т.п. |
