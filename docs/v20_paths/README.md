# Пути (Paths) по правилам V20

## About The Pull Request

Переделка морали вампиров по настолке V20 (Vampire: The Masquerade 20th Anniversary Edition).

### Термины


| Термин                              | Коротко                                                                                                                       |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Путь (Path)                         | Мораль вампира. У каждого вампира один Путь: Человечность (Humanity) или один из Путей Просветления (Paths of Enlightenment). |
| Рейтинг Пути                        | Число от 1 до 10: насколько крепко вампир держится своего Пути. Стартовый рейтинг — сумма двух добродетелей Пути.             |
| Иерархия грехов (Hierarchy of Sins) | Таблица из 10 проступков. У каждого свой рейтинг: чем ниже рейтинг греха, тем тяжелее грех.                                   |
| Деградация (Degeneration)           | Потеря очка рейтинга после греха.                                                                                             |
| Искупление (Atonement)              | Возврат потерянного очка через поступок, угодный Пути.                                                                        |
| Добродетели (Virtues)               | Статы, которыми бросают проверки морали. У каждого Пути своя пара, см. ниже.                                                  |
| Облик (Bearing)                     | Бонус или штраф к определённым броскам, зависит от рейтинга Пути.                                                             |
| Прозвище                            | Как называют последователей Пути. На механику не влияет, просто для отыгрыша.                                                 |


### Добродетели

У каждого Пути две добродетели: одна для проверок совести, другая для борьбы со Зверем. Смелость (Courage) есть у всех.


| Добродетель                                         | Для чего                                                                      |
| --------------------------------------------------- | ----------------------------------------------------------------------------- |
| Совесть (Conscience) или Убеждённость (Conviction)  | Бросок, чтобы не потерять рейтинг после греха и чтобы вернуть его Искуплением |
| Самоконтроль (Self-Control) или Инстинкт (Instinct) | Сопротивление безумию (Frenzy) и голоду                                       |
| Смелость (Courage)                                  | Сопротивление Ротшреку (Rötschreck), панике от огня и солнца                  |


Инстинкт работает не так, как Самоконтроль. Вампир с Инстинктом **всегда** впадает в безумие, но внутри него может «оседлать волну» (ride the wave): успешный бросок Инстинкта даёт контроль над действием.

### Как теряется рейтинг

1. Персонаж совершает грех из таблицы своего Пути.
2. Если рейтинг греха **не выше** текущего рейтинга Пути, делается бросок Совести или Убеждённости, сложность 8. Грехи «легче» текущего уровня персонажа уже не беспокоят.
3. Результат броска:
  - успех — ничего не теряется;
  - провал — −1 к рейтингу;
  - критический провал (ботч, botch) — −1 к рейтингу, −1 к добродетели и психическое расстройство (derangement).
4. Потеря действует **до конца раунда**. В новом раунде рейтинг снова равен сумме добродетелей из анкеты.

Пример: у вампира на Человечности рейтинг 7. Кража (грех 7) требует броска. Мелкий эгоизм (грех 9) — нет: на рейтинге 7 персонаж к нему уже равнодушен.

### Как рейтинг восстанавливается (Искупление)

1. В файле каждого Пути есть таблица поступков, которые Путь одобряет.
2. После поступка делается бросок Совести или Убеждённости, сложность 7. Успех даёт +1 к рейтингу.
3. Ограничения:
  - не больше **2 очков за раунд**;
  - каждый поступок засчитывается **один раз за раунд**;
  - выше стартового рейтинга подняться нельзя;
4. Если рейтинг и так полный, поступок ничего не даёт и лимит не тратит.
5. Провал броска лимит не тратит, но этот поступок в раунде больше не засчитывается.

Числа (лимит, сложность) пока обсуждаются.

### Облик (Bearing)

От рейтинга Пути зависит сложность бросков, связанных с Обликом. Например, Облик Угроза (Menace) у Пути Дикого Сердца влияет на запугивание.


| Рейтинг Пути | Сложность таких бросков |
| ------------ | ----------------------- |
| 10           | −2 (легче)              |
| 9–8          | −1                      |
| 7–4          | без изменений           |
| 3–2          | +1                      |
| 1            | +2 (сложнее)            |


Пометка ❓ в таблице ниже значит, что подходящих бросков в игре пока нет.

### Создание персонажа на Пути Просветления

- Стартовый рейтинг не выше 5.
- Сила воли (Willpower) не меньше 5.
- Как сменить Человечность на другой Путь посреди игры ❓: в настолке это делается через испытание под присмотром ведущего.

## Why It's Good For The Game

- Каждый Путь играется по-своему, а не как «Человечность наоборот».
- Механика опирается на настолку V20.
- Искупление даёт исправиться в том же раунде, а лимит не даёт его фармить.
